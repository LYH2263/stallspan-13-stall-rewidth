# StallSpan 市集摊档开间

沿街段一维 First-Fit 开间分配，挡柱不可被摊位跨越，输出分配图与放不下清单。

技术栈：Python 3.12 / FastAPI / SQLAlchemy / PostgreSQL / Vue 3 / TypeScript / Vite

## 启动

```bash
docker compose up --build
```

| 服务 | 地址 |
| --- | --- |
| 前端 | http://localhost:4700 |
| API | http://localhost:9700 |
| API 文档 | http://localhost:9700/docs |
| Postgres | localhost:5448 |

健康检查：`GET http://localhost:9700/api/health`

## 使用说明

1. 在「集日」「街段」确认开市日与可用宽度。
2. 在「摊主」「挡柱」维护需求宽度与障碍位置。
3. 打开「分配图」执行一维开间分配。
4. 在「放不下」查看无法安置的摊位。

### 本轮临时抬优先

在「分配带」页点「本轮临时优先」打开运行抽屉，可为若干摊主指定本轮临时优先（1–9）：

- 只影响这一次现算预览或确认入库，**不写回登记优先**；临时与登记冲突时本轮只认临时。
- 「现算预览」只算不落库；「确认入库」才把占位次序与放不下排队按临时优先写入。
- 任何一条临时值非法（非 1–9、摊主不存在、重复）都**整次拒绝**，登记、图、放不下均不变。
- 「清除临时」清空本轮临时表并立即按登记优先重分，不会继续吃临时缓存。
- 分配表与放不下清单同时展示登记优先 / 本轮临时 / 生效优先三套数，便于对照。

种子数据中「巨型舞台车」登记优先 9、全场最宽：未抬时放不下；本轮抬到 1 即可进图；清除临时后回到优先 9 的劣势。
